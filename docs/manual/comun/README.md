# Lo común a los tres manuales

Esto es lo que **no cambia** según dónde tengas la aplicación: qué significa cada
número, quién puede hacer qué, y las reglas del reparto.

Los tres manuales —[web](../web/README.md), [APK](../apk/README.md) y
[escritorio](../escritorio/README.md)— apuntan aquí. Si algo de esto cambia, se
cambia aquí y en un solo sitio.
